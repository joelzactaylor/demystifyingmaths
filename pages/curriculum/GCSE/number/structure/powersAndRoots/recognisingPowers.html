Before this page: be able to read and evaluate powers using index notation.

Reading a power backwards

Evaluating 3^4 gives 81. Recognising a power runs that calculation backwards: starting from 81, name the power that makes it, 3^4.

evaluate3^4 ⟶ 81

recognise81 ⟶ 3^4

81 does not show its four factors of 3; recognising it means knowing the fact 3^4 = 81. Swapped, the base and index name a different number: 4^3 = 64.

Squares and cubes

A square is a product of two equal factors: 49 = 7 × 7.

A cube is a product of three equal factors: 64 = 4 × 4 × 4.

  1. 1^31
  2. 2^38
  3. 3^327
  4. 4^364
  5. 5^3125
  6. 10^31,000

Both 0 and 1 are square and cube numbers: 0^2 = 0^3 = 0, and 1^2 = 1^3 = 1.

A number in the list of squares is a square; a whole number between two consecutive squares is not, and the same holds for cubes.

50 is not a square It lies between consecutive squares.7^2 = 49 < 50 < 64 = 8^2

100 is not a cube It lies between consecutive cubes.4^3 = 64 < 100 < 125 = 5^3

Powers of 2, 3, 4 and 5

Each row starts at its base and keeps multiplying by it, so a number’s place in its row is its index.

Powers of 2
2, 4, 8, 16, 32, 64, 128, 256, 512, 1,024
Powers of 3
3, 9, 27, 81, 243
Powers of 4
4, 16, 64, 256, 1,024
Powers of 5
5, 25, 125, 625, 3,125

243 appears fifth in the powers of 3243 = 3^5

200 lies between consecutive powers of 2128 < 200 < 256

One number can have several power names

The six factors of 2 in 64 can be grouped into three factors of 4 or two factors of 8.

64 = 2^6 = 4^3 = 8^2

In these three names for 64, the larger base carries the smaller index. “Write 64 as a power of 4” asks for the one with base 4.

Common mistakes

  • Reading the base and the index the wrong way round 125 is 5^3, not 3^5: five factors of 3 multiply to 243.
  • Answering with a base the question did not ask for Asked for 81 as a power of 9, 3^4 is a true name with the wrong base: the four factors of 3 group into two factors of 9, so 81 = 9^2.

Summary

  1. Recognising a power reverses evaluating one: 81 is 3^4 because four factors of 3 multiply to 81.
  2. The squares worth recalling run 1, 4, 9, 16, 25, 36, 49, 64, 81, 100, 121, 144, 169, 196 and 225.
  3. The cubes worth recalling are 1, 8, 27, 64 and 125, together with 10^3 = 1,000.
  4. A whole number between two consecutive squares is not a square, and one between two consecutive powers of 2 is not a power of 2: 49 < 50 < 64 rules 50 out.
  5. One number can carry several power names, since 64 = 2^6 = 4^3 = 8^2, but swapping a base and its index changes the value.
