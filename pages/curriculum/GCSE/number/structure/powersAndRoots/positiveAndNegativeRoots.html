  7. Positive and negative square roots

Before this page: be able to square a whole number using index notation, and know the square root as the reverse of squaring from square roots.

Two numbers square to 49, and the root sign names one of them

7 and −7 have the same square: (−7) × (−7) = 49, not −49, because two negatives multiply to a positive, the rule set out in full on multiplying and dividing negative numbers:

√49 = 7

  1. Of 7 and −7, which both square to 49, the sign names the non-negative one.

−7 is a square root of 49, and it is written −√49. 7, the root the sign names, is called the principal square root.

One symbol stands for one number. If √49 stood for 7 and −7 at once, √49 + 1 would be both 8 and −6, and the calculation could not go on.

x² = 49 has two solutions

x^2 = 49 asks which numbers square to 49, and two do: 7 and −7, the equation's solutions.

x = ±7 records both values of the unknown on one line, and ±7 is read “plus or minus 7”.

Example: solve x^2 = 81

Find both numbers that square to 81, then record them on one line.

  1. x^2 = 81 81 is positive, so two numbers square to it.
  2. 9 × 9 = 81 81 is 9², one of the squares of 1 to 15, and (−9) × (−9) = 81 as well.
  3. x = ±9 Both are solutions, and ±9 records them on one line.

x² = 0 has one solution, and x² = −9 has none on the number line

x^2 = 0 has one solution, 0, because 0 and −0 are the same number.

No number on the number line squares to −9. A square is a number multiplied by itself, so its two factors carry the same sign and their product is positive or zero.

Common mistakes

  • Putting a plus-or-minus on the root sign √25 = ±5 is wrong: the sign names the non-negative root alone, so √25 = 5. It is x^2 = 25 that has the answer ±5.
  • Giving one solution to x² = 36 6^2 = 36 and (−6)^2 = 36, so an answer of 6 alone to x^2 = 36 leaves out −6: x = ±6.
  • Passing a minus through a squaring (−4)^2 = 16, not −16, so x = −4 does not solve x^2 = −16; no number on the number line does.

Summary

  1. Every positive square is reached from two numbers that differ only in sign: 49 from 7 and from −7.
  2. The sign √49 names the principal square root, so it stands for the single number 7.
  3. x^2 = 49 asks for every number that squares to 49, and x = ±7 records both answers on one line.
  4. x^2 = 0 has the one solution 0, and no number on the number line squares to −9, since a number on the line multiplied by itself is positive or zero.
