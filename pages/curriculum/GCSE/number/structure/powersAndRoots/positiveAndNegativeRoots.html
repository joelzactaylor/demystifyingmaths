Two numbers square to 49

Before this page: be able to square a whole number using index notation, and know the square root as the reverse of squaring from square roots.

7 × 7 = 49, and (−7) × (−7) = 49. A number and its negative have the same square.

Multiplying two negatives gives a positive, which is why (−7) × (−7) comes to 49 rather than −49, and multiplying and dividing negative numbers sets that rule out in full.

What the root sign names

√49 = 7. The sign names one number, and the one it names is never negative.

√49 = 7

  1. 7 and −7 both square to 49.
  2. The sign names the non-negative one of the two.

−7 is a square root of 49, and it is written −√49. The one the sign names, 7, is the principal square root.

One symbol stands for one number. Were √49 to stand for 7 and −7 at once, √49 + 1 would come to both 8 and −6. Neither value could then be carried into the next line.

Solving x² = 49

x^2 = 49 asks which numbers square to 49. 7 × 7 = 49 and (−7) × (−7) = 49, so the equation has two solutions.

x = ±7 records both solutions on one line, and ±7 is read “plus or minus 7”.

A sign that names one, a question that asks for both

√49 = 7 is a number, and 7 is the whole of it. x^2 = 49 is a question about the unknown x, and it is answered by x = ±7.

Example: solve x^2 = 81

Find both numbers that square to 81, then record them on one line.

  1. x^2 = 81 81 stands on the right, so the question is which numbers square to 81.
  2. 9 × 9 = 81 The squares of 1 to 15 give 9, and (−9) × (−9) makes the same 81.
  3. x = ±9 Squaring either value returns the 81 the equation started from, which is the check.

How many numbers square to a value

x^2 = 0 has one solution. 0 is its own negative, so the two values that a positive square would give fall together on 0.

No number on the number line squares to −9. A square is a number multiplied by itself, so its two factors carry the same sign and their product is positive.

Common mistakes

  • Wrong idea: √49 = ±7 Why it is wrong. ±7 answers x^2 = 49; the sign names the non-negative root alone. Correct form. √49 = 7, while x^2 = 49 gives x = ±7
  • Wrong idea: x^2 = 49, so x = 7 Why it is wrong. (−7)^2 = 49 as well, so an answer of 7 alone leaves one of the two solutions unwritten. Correct form. x = ±7
  • Wrong idea: x^2 = −9, so x = −3 Why it is wrong. The minus sign does not pass through the squaring: (−3)^2 = 9, which is 9 and not −9. Correct form. x^2 = −9 has no solution on the number line
  • Wrong idea: x^2 = 0, so x = ±0 Why it is wrong. ± separates two values, and 0 and −0 are the same number, so it separates nothing. Correct form. x = 0

Remember

  1. Every positive square is reached from two numbers that differ only in sign: 49 from 7 and from −7.
  2. The sign √49 names the principal square root, so it stands for the single number 7.
  3. x^2 = 49 asks for every number that squares to 49, and x = ±7 records both answers on one line.
  4. x^2 = 0 has the one solution 0, and no number on the number line squares to −9, since a number on the line multiplied by itself is positive or zero.
