Introduction

Column addition turns one large calculation into a sequence of small additions. The numbers are written so that equal place values form columns, and those columns are added from right to left.

The arrangement matters. Ones must sit beneath ones, tenths beneath tenths, and so on. Once the place values are aligned, the same method works for whole numbers, decimals, money and measures.

Build the calculation

Alignment
+

Use positive numbers with up to five whole-number digits and three decimal places.

Align equal place values

Begin with the decimal points directly beneath one another. The empty hundredths place in 956.7 is held by a zero, so it can be read as 956.70.

Why the columns must align

Each column contains quantities of the same size. A digit in the tens column represents groups of ten; a digit in the hundredths column represents groups of one hundredth. Adding digits from different columns would combine unlike quantities.

Correct alignment
12.40 +03.75

The decimal points line up, so every digit is paired with the same place value.

Incorrect alignment
12.4 +3.75

Aligning the final digits places hundredths beneath tenths and changes the calculation.

Align decimal points, not edges

Write 12.4 as 12.40 when the extra zero makes the columns clearer. A zero added to the end of a decimal does not change its value.

Regrouping a column

A single place-value column can hold only one result digit. If a column totals 10 or more, split the total into ones and tens. Write the ones in the current column and regroup the tens into the column immediately to the left.

→regroup
1 ten

For example, if the ones column contains 8 + 6 + 1 = 15, write the 5 in the ones column and regroup the 1 ten. That regrouped 1 belongs to the tens column, where it is included in the next addition.

Adding whole numbers

Whole-number calculations follow exactly the same place-value structure. Keep the digits in clear columns and record regrouped amounts above the column in which they will be used.

Example: calculate 4,687 + 2,759

Work from the ones column towards the thousands column.

  1. 7 + 9 = 16Write 6 ones and regroup 1 ten.
  2. 1 + 8 + 5 = 14Include the regrouped ten; write 4 tens and regroup 1 hundred.
  3. 1 + 6 + 7 = 14Write 4 hundreds and regroup 1 thousand.
  4. 1 + 4 + 2 = 7The thousands column completes the answer: 7,446.

Adding decimals

Decimal points remain in a fixed column. Place a decimal point in the answer directly beneath the other decimal points, then add from the smallest occupied place towards the left.

Example: calculate 18.75 + 6.9

Write 6.9 as 6.90 so that both hundredths places are visible.

  1. 5 + 0 = 5Write 5 in the hundredths column.
  2. 7 + 9 = 16Write 6 in the tenths column and regroup 1 one.
  3. 1 + 8 + 6 = 15Write 5 in the ones column and regroup 1 ten.
  4. 1 + 1 = 2Place the decimal point in its fixed column: 18.75 + 6.90 = 25.65.

Keep the unit attached to the answer

In a money calculation, £18.75 + £6.90 = £25.65. In a measure calculation, convert both quantities to the same unit before arranging the columns.

Check the result

An estimate will not reproduce the exact answer, but it should confirm its size. Round each addend to a convenient value, add the rounded numbers mentally, and compare this estimate with the column result.

Exact calculation4,687 + 2,759
→
Round to hundreds4,700 + 2,800
→
Estimate7,500

The exact answer, 7,446, is close to 7,500. An answer such as 744.6 or 74,460 would be far from the estimate and would reveal a place-value error.

Common mistakes

  • Aligning the final digitsFor decimals of different lengths, align the decimal points. Final digits may represent different place values.
  • Forgetting a regrouped amountWrite each regrouped digit above the next column and include it before adding that column.
  • Writing two digits in one columnIf a column totals 13, write 3 in that column and regroup the 1 into the column to its left.
  • Moving the decimal pointThe decimal point does not move during addition. Copy it straight down into the answer line.
