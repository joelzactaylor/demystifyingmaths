Author note — to cover

Find the class containing the median of grouped data: locate the middle position from the total frequency, run a cumulative count through the classes, and state the class in inequality notation. No linear interpolation for an exact value, which is A level. Graphical median estimates are Higher, via cumulative frequency graphs. Both tiers. (S4)
