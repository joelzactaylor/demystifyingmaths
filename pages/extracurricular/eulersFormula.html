Introduction

"What is Euler's Formula?" may seem like the main question for me to answer on this page, but I want to start with a simpler question: "Who is Euler?"

Why, this man of course! He lived in the 1700s, and he did so many amazing things for maths, if you want to find out more here's the wiki. (It's too much to transcribe here.)

A short summary though:

  • Literally invented the function notation f(x)

  • Invented most of calculus

  • Invented graph theory – which powers most of the modern world

  • Invented the precursors to Venn Diagrams

  • Oh, and he also invented PI! As in, the number 3.14159265358979323...
    (Technically he didn't invent the number because all numbers already exist. But he popularised the symbol we use for it.)

Yeah, he was the GOAT. (One of them, at least.)

Anyway, enough history. We're here for the maths! Let's go.

Euler's Formula

Euler obviously created a fair few formulas, given his lifetime spent studying and inventing new mathematics, yet this is the one that bears his name.

That's because this formula is so incredibly elegant – and I'm sure you'll see why:

It links the exponential function e x with the imaginary unit i and the trigonometric functions sin and cos : it joins together parts of mathematics that seem completely unrelated without it.

The reason this makes it so famous and respected is because mathematicians absolutely love discovering hidden connections. That's really what maths is all about.

On this page, I will demonstrate three completely different ways of proving that this formula is correct, and then we'll explore its uses.

Method 1 – Following the Gradient

This is my favourite method, because it doesn't rely on very abstract steps in the proof. Each step is mathematically rigorous, as should be the case with any good proof, but every step is comprehensible in plain language too.

I'll write the steps out in the most correct notation I can, and then explain each one. I worked out this proof myself, not two days ago – two whole years after I first started searching for it. (I wasn't working non-stop, don't worry. It was very intermittent.)

The first step is analysis of the exponential function:

By "analysis" I mean "please play with my simulation".

The green line represents the function f ( x ) = e x .

The blue dot A is a point on that curve.

The red line through A is a tangent to the function. This means it represents how steep the curve is at point A.

Careful observation would reveal that the slope of the tangent (called the gradient of the function) is exactly the same as the vertical coordinate of the function at every point.

d d x ( e x ) = e x

The symbol d/dx means "the slope of". It's called the gradient function of whatever comes after it (often in brackets, but they can sometimes be omitted). In fact, there is a more general form of this rule that you could uncover by playing with different simulations, which describes the gradient of a variation of the exponential function:

d d x ( e a x ) = a e a x

This says if you compress the green curve horizontally by a factor a , then the slope will be a times steeper. Take a moment to convince yourself of this fact.


For the next step, we are going to set a equal to the imaginary unit, i .

If you are unfamiliar with complex numbers, I suggest you go no further until you have read at least some of this page, otherwise this will be very confusing for you.

Setting a = i gives us this equation, and this gradient function:

d d x ( e i x ) = i e i x

Our challenge is to plot this function.

The easiest method is to start from a point we can work out, like x = 0 , and keep making tiny steps in the right direction based on the gradient function.

This is now a complex function, so we plot on a complex plane instead of a single axis. Imagine it like this - f ( x ) is a point on the plane which wanders around as we change x , as though x represents time.

Set x (as time) to zero. This is what we have:

f ( 0 ) = e 0 = 1

And we can draw this on the complex plane:

Now let's work out the derivative (gradient) of the function at x = 0 .

d d x ( e i x ) = i e i x   ⇒   d d x ( e i 0 ) = i e i 0 = i e 0 = i

The gradient is imaginary! But don't panic, this just means we have to "take a small step in the imaginary direction".

The notation f ' ( x ) is another way to represent the gradient function.

Let's advance x (time) by a small amount. This means nudging our point in the direction the gradient arrow is pointing:

The gradient changes now!

In fact, we can predict exactly how it will change:

f ' ( x ) = i e i x = i f ( x )

The gradient of the function is always exactly i times the function itself. We know that multiplying by i represents a rotation of 90° anticlockwise in the complex plane, so we can predict that the gradient arrow in our drawing will always be pointing perpendicular to the arrow from the origin to the point.

Let's increment x again:

Now we can form a conclusion about the path the point will trace out. It is always moving in the direction perpendicular to its radial direction, so it's distance from the origin can never increase.

If it always stays at the same radius, but keeps moving, then it must, logically, trace out a circle:

The radius of the circle must be 1, because we know is passes through the point 1 at x = 0 .

Therefore we can say, with absolute certainty, that the function f ( x ) = e i x traces out the unit circle on the complex plane.

Let's put that in notation!

∀ f ∈ ℂ ℝ , ∀ x ∈ ℝ ⇒ f ( x ) ⊥ i f ( x ) ⇔ f ( x ) · i f ( x ) = 0

Alright, don't scream. I'll break it down.

∀ f ∈ ℂ ℝ reads as "for every function that takes a real number as input and outputs a complex number".

∀ x ∈ ℝ reads as "where x is a real number", i.e. the input to said function.

f ( x ) ⊥ i f ( x ) reads as "function f of x is perpendicular to i times function f of x ". The ⊥ symbol is also used to represent disjoint sets, but this uses its other meaning.

f ( x ) · i f ( x ) = 0 reads as "the dot product of f ( x ) and i f ( x ) is equal to zero". This is simply a way of clarifying exactly what we mean by saying they are perpendicular.

All this is a very complete way for us to explain using symbols that the gradient vector will always be perpendicular to the point vector.

Next:

∵   f ' ( x ) ⊥ f ( x )   ⟹   d d x ( | f ( x ) | ) = 0

This one's simpler. "Given that the gradient is perpendicular to the point vector, the rate of change of the distance from the origin to the point is zero". AKA the radius doesn't change.

∴   f ( ℝ ) = 𝕊 1

"Therefore, if you apply the function to every real number, the set of outputs will match up with the unit circle". The unit circle is a 1-dimensional sphere, labelled 𝕊 1 , in a system where a 2-sphere is the surface of a 3D ball, a 3-sphere is the surface of a 4D ball, and so on.

And that proves the function traces a circle! But wait... how fast does it trace it?

We know that at x = 0 it has a value of 1 (i.e. an angle around the circle of zero, since we designate that the starting point), but how much do we have to increase the input x before we get all the way around?

Well, this is easy compared to the first phase.

| f ( x ) | = 1 ⟹ | f ' ( x ) | = | i f ( x ) | = | i | · | f ( x ) | = 1

"Since the radius is always 1, the derivative always has a magnitude of 1 as well (regardless of what direction it points)".

And what does a gradient of magnitude 1 mean? It means that the input and the output are moving at the same rate – literally that | Δ output | ÷ | Δ input | = 1 .

So the point traces the unit circle at a rate of 1 unit of arc length per unit change in input, and it also maintains a constant speed all the way around (which might seem obvious, but we hadn't proved it explicitly yet).

The circumference of a circle C = 2 π r , so the circumference of a unit circle is exactly 2 π . So when x starts from zero and moves along the number line to 2 π , the output of f ( x ) traces the full circumference of the unit circle.

So there we have it.

The function f ( x ) = e i x traces the path of a unit circle in the complex plane, by rotating the point ( 1 + 0 i ) by x radians anticlockwise around the origin. We can deduce radians because 1 radian is defined to subtend 1 unit of arc length on the unit circle.

Now here's another way to make a unit circle:

{ x ( t ) = cos ( t ) y ( t ) = sin ( t )

This is called a parametric equation – we define x and y separately in terms of t, and as t increases, the shape will be traced.

Cosine and sine are defined as the x and y coordinates of a point on the unit circle, so by definition, any unit circle traversed at unit speed is described parametrically as (cos t, sin t).

Last step! Equate the 2 different ways of drawing a circle. Define a parametric unit circle in the complex plane by adding the real x coordinate and the imaginary y coordinate:

f ( t ) = x ( t ) + i y ( t ) = cos ( t ) + i sin ( t )

And equate! (Let x and t both be identified together as φ .)

e i φ = cos ( φ ) + i sin ( φ )

And that is the famed Euler's Formula. Hope you enjoyed the ride. Now here are some other ways to prove it's correct.

Method 2 – Maclaurin Series

This method takes the functions that Euler's formula is built from and breaks them down into an infinite sum of simple polynomial building blocks. These sums are called Maclaurin series (plural).

If you're not familiar with Maclaurin Series, my page on them is here.

The idea is simple: if you know everything about how a function behaves at just a single point, you can use its derivatives to build a polynomial that matches its curve perfectly. A polynomial is just any expression where every term has the form a x n .

Let's look at the Maclaurin series for our three core functions. First, the exponential function:

e x = 1 + x + x 2 2 ! + x 3 3 ! + x 4 4 ! + ⋯

The exclamation mark represents a factorial (for example, 3 ! = 3 × 2 × 1 = 6 ). The pattern in this equation keeps going forever. Next, we look at the patterns for our two trigonometric functions, cosine and sine:

cos ( x ) = 1 − x 2 2 ! + x 4 4 ! − x 6 6 ! + ⋯ sin ( x ) = x − x 3 3 ! + x 5 5 ! − x 7 7 ! + ⋯

Notice the incredible symmetry here. Cosine takes all the even powers of x and alternates their signs, while sine takes all the odd powers and alternates their signs. If you were to add them together directly, they almost—but not quite—look like the exponential function. The signs are stopping them from matching up.

To fix the signs, we are going to swap out our real number x in the exponential function for an imaginary one: i x .

Remembering that i 2 = − 1 , let's write down a list of powers of the imaginary unit:

  • i 0 = 1
  • i 1 = i
  • i 2 = − 1
  • i 3 = − i

After this, the pattern repeats, with i 4 = 1 .

If we substitute i x in place of x in the Maclaurin Series for the exponential function, we get this:

e i x = 1 + i x + ( i x ) 2 2 ! + ( i x ) 3 3 ! + ( i x ) 4 4 ! + ⋯ = 1 + i x − x 2 2 ! − x 3 3 ! i + x 4 4 ! + x 5 5 ! i − ⋯

Now for the magic step. Let's group all the terms that do not have an i together, and separate out all the terms that do have an i :

e i x = ( 1 − x 2 2 ! + x 4 4 ! − x 6 6 ! + ⋯ ) +   i ( x − x 3 3 ! + x 5 5 ! − x 7 7 ! + ⋯ )

And hey, hold on a second! Do those sequences look familiar?

They're exactly the series for sine and cosine! So we can substitute, and simply relabeling x to φ gives us:

e i φ = cos ( φ ) + i sin ( φ )

And there it is! By simply breaking the functions down into their polynomial building blocks, the hidden connection between trigonometry and exponential growth becomes completely undeniable.

Method 3 – Calculus and Logarithms

This third method is a beautifully elegant alternative. Instead of tracking spinning vectors or adding up infinite polynomials, we are going to use pure, classic calculus to show that trigonometry and complex exponents are fundamentally wrapped up in the exact same mathematical skin.

Our strategy here is to start directly with the trigonometric side of Euler's formula, bundle it into a single temporary function, and use algebra to see what it integrates into. Let's define our mystery function, which we will call z :

z = cos ( x ) + i sin ( x )

Now, let's take the derivative of this entire function with respect to x . If you remember your standard calculus rules, the derivative of cosine is negative sine, and the derivative of sine is cosine:

d z d x = − sin ( x ) + i cos ( x )

This looks a bit messy because of that negative sign. But here is the magic trick: remember that i 2 = − 1 . This means we can deliberately replace that negative sign in front of the sine term with i 2 instead!

d z d x = i 2 sin ( x ) + i cos ( x )

Now that both terms have an i attached to them, we can factor it out completely. Let's see what happens when we pull that i out to the front:

d z d x = i ( i sin ( x ) + cos ( x ) )

If we swap the order of the two terms inside the parentheses, a massive realization hits us:

d z d x = i ( cos ( x ) + i sin ( x ) )

Look closely at what is inside those brackets. It is exactly our original definition of z ! This means we can substitute z straight back into the right side of the equation. This gives us a neat, clean differential equation:

d z d x = i z

To solve this, we are going to use a classic technique called separation of variables. We will shuffle the equation around so that all the z variables are hanging out on the left side, and the x variables are over on the right:

1 z d z = i d x

Now, let's slap an integration sign on both sides of the equation and integrate them:

∫ 1 z d z = ∫ i d x

If you remember your calculus rules, the integral of 1 / z is the natural logarithm ( ln ), and integrating a constant like i with respect to x just gives us i x . Don't forget to add our constant of integration, C :

ln ( z ) = i x + C (Here we use the chain rule in reverse: since z is a nonzero complex-valued function of the real variable x , d d x ( ln z ) = 1 z d z d x holds, and z is never zero on the unit circle.)

To get rid of the natural logarithm and solve for z , we raise both sides as exponents base e (the exponential and the logarithm are inverse functions, so they cancel out):

z = e i x + C = e C e i x

To find out what that constant e C actually is, we can plug in a known starting value. Let's look at what happens when x = 0 . From our very first definition, z = cos ( 0 ) + i sin ( 0 ) = 1 + 0 = 1 .

Plugging x = 0 and z = 1 into our new equation gives us 1 = e C × e 0 , which means e C is exactly 1 !

This simplifies our equation down beautifully to:

z = e i x

Finally, let's swap our original trigonometric definition of z back into the left side. If we switch the sides around and use our favorite phase angle symbol φ instead of x , we cross the finish line:

e i φ = cos ( φ ) + i sin ( φ )

And there you have it—three entirely different paths through the mathematical landscape, all leading to the exact same stunning equation.
