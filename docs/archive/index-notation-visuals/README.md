# Original powers visualisations

Preserved before the October 2026 Powers and roots refresh. These are reference
sources, not pages served by the curriculum. The original HTML is `.html.txt`
to distinguish it from a maintained lesson.

The most useful extracurricular material is the rotating lattice: powers can
be represented by repeated dimensions, beyond the familiar square and cube.
The JS includes trackball/quaternion rotation, higher-dimensional plane
rotations, a worker-backed lattice painter, and step-by-step square/cube and
factor-grouping scenes. The CSS and original markup preserve its required DOM.

To revive it, extract a self-contained scene for an extracurricular page;
do not put the old whole-page script back on the new lesson. Recheck keyboard
access, reduced motion, canvas text sizes and static fallbacks. The new lesson
retains repeated multiplication, area/volume meaning and a simpler live power
calculator; it no longer makes learning notation depend on these scenes.
